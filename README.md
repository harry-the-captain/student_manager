## 🧠 About The Project

- 🎓 Student Manager is a web-based application.
- Built to simplify academic data handling for teachers and admin.
- Solves the issue of cluttered student records and manual data entry.

---

## 🔥 Features

- ✅ Add/Edit/Delete student records
- 📋 View student list with search functionality
- 🧩 Responsive layout for all screens
- 🧠 Reusable widgets for clean UI
- 🔍 Search student data dynamically
